# 出片风格 D · 章节档案

2026-10-11 定为竖版默认风格（参考：抖音「阿杜Next」模板编号 07 的版式思路，元素自己实现）。范例成片：U 盘项目 v6（`remotion/films/cmujxgbz6000eg417ngfzoolz-v6/`）。

## 目的

把「每条都重新想画面」变成「固定模板 + 换内容」：开场钩子、章节、编号卡、人物窗的形态切换都有固定做法，出片时只设计内容。

## 组成（`remotion/kit/chapter.tsx`）

| 部分 | 做法 |
|---|---|
| 背景 | 暖白纸 `#F4EFE6` + 点阵 |
| 顶部章节条 | `// 章节号 · 章节名 ……… 署名 时间码`，下面每章一格进度（已过黑、当前洋红、未到浅灰）；章节号与时间码由组件生成 |
| 人物窗 | `hero` 大圆角窗（开场、转折）↔ `circle` 洋红描边圆窗（正文，居中或偏左）↔ `off` 收起（全屏图形）；0.6 秒平滑变形 |
| 字幕 | 白字黑描边，关键词黄色 |
| 积木 | `NumberCard` 编号卡、`Tag` 黄标签、`Pink` 洋红强调、`headline()` 粗黑大字、`Polaroid` 相纸（可模糊） |
| 装饰 | 右下黄黑警示条 |

## 取舍

- **避开抖音遮挡**：圆窗和字幕在同一条中线（x≈455），不进右侧点赞列（x≥860）；顶部 300 留空。所以圆窗没有按参考视频放在右下角。
- **和风格 C 并存**：旧片子用 `Frame` 照样能重新渲染；横版仍用风格 C。
- **不做双语字幕**：英文要机翻，容易出错，先不做。
- 内容区随人物窗形态变化：hero 时只剩上方 960×270 标题区，circle 时 960×620，off 时 960×990。
