## 「开源项目推荐」系列（2026-10-09 登记）

**来源**：用户看了两个同类账号——
- 索亚加德（2.6 万粉，92 万赞，193 个作品）：「开源项目大合集」系列已做到第 158 集。不露脸；开头是外网帖子截图加表情包，中间是项目官网和演示录屏，配大字幕和配音，30–40 秒；封面是表情包加紫色描边大字。靠量和系列感，偶尔爆款（1.8 万赞）。
- Geek Geezer / 极客老登（新号）：同类题材，精致动态设计风（深色背景、渐变大标题、录屏放在圆角卡片里），约 1 分钟；和索亚加德撞了同一条新闻。

**定位**：作为主号的补充系列（主号合集或新号），不替代主号的真人亲测路线。

**讲法（与同类号拉开差距）**：不只播报「XX 被开源了」，而是「真人上手试开源项目」——装到哪一步卡住、能不能用、适不适合普通人。接上主号「真实亲测、翻车也说」的定位（U盘生意本身就源于「开源项目普通人装不上」）。

**分两档**：
- 快讯档：30 秒，AI 配音加画面，追热点、占量；可高度自动化。
- 亲测档：60–90 秒，用户出镜加口播，只做真试过的项目；快讯档里反响好的再升级成亲测档。

**可复用的现有能力**：每日选题（可加「开源项目」来源）、写稿（资讯整理类不存在编经历问题）、Remotion 出片模板（小窗 + 内容区 + 字幕，横竖版都有）、网页出片助手。

**需要新做的**：
- 开源项目来源：GitHub Trending、外网帖子等，需评估抓取方式。
- 读 README 生成稿子。
- 自动截官网、录演示。
- AI 配音（快讯档）。
- 封面风格。

**风险**：同题撞车多，快讯档拼速度；信任和转化低于主号，主要价值在占量与给主号供题。
