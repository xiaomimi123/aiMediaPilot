# 界面改版设计：行动优先总览 + 暖白卡片

- 日期：2026-10-01
- 状态：待用户审阅
- 样稿：本地 `.superpowers/brainstorm/15496-1790849110/content/`（dashboard-layout / visual-style / workspace-layout，未入库）
- 取代：2026-09-08 的深色 Linear 风（`docs/superpowers/specs/2026-09-08-ui-dark-handoff/`）

## 1. 目标

解决四件事：视觉不好看；功能太散找不到；每天的流程不顺；手机上也要好用。

## 2. 已确认的决策

| 问题 | 决定 |
|---|---|
| 首页 | 数据仪表盘，按"行动优先"布局：最上「今天」，再指标、走势、作品对比 |
| 仪表盘内容 | 账号走势、作品表现对比、待处理与在做的作品、预测与对标——全部放 |
| 导航 | 5 项：总览 / 作品 / 选题 / 助手 / 设置；手机为底部标签栏 |
| 视觉 | 暖白卡片（米白底、白卡片柔和投影、橙棕强调、大数字衬线） |
| 深色模式 | 不做；提词器保持黑底白字（录制工具的功能需要） |
| 作品工作区 | 顶部六步步骤条 + 内容居中；编导对话收起为右下角按钮，展开为右侧抽屉（手机底部滑出） |
| 实施方式 | 换设计变量 + 把平铺列表 / 框改成卡片样式；页面逻辑不改；不引入新的界面或图表库 |

## 3. 结构与导航

### 3.1 入口

| 入口 | 路径 | 内容 | 来源 |
|---|---|---|---|
| 总览 | `/` | §5 仪表盘 | 原首页账号卡与提示 |
| 作品 | `/works` | 全部项目卡片；阶段筛选（全部 / 写稿中 / 录制中 / 成片 / 已发布）；按更新时间或预测排序；新建项目 | 原首页项目列表 + 原「复盘」已发布列表 |
| 选题 | `/topics` | 不变，换样式 | — |
| 助手 | `/assistant` | 不变，换样式 | — |
| 设置 | `/settings` | 分组卡片：账号定位 / 模型 / Obsidian / 每晚任务 / 写法库 / 预测公式 / 依赖体检；页内锚点导航 | 原设置 + 原「定位」+ 原「复盘」的写法库与公式建议 |

- 旧地址：`/retro` → `/works?stage=published`；`/persona` → `/settings#persona`（永久重定向）。项目页 `/projects/<id>` 不变。
- 侧栏（≥ 768px）：宽 224，顶部产品名，5 项图标 + 文字，当前项浅橙底。
- 底部标签栏（< 768px）：5 项图标 + 两字，当前项橙色；页面底部留出标签栏高度，不遮内容。

### 3.2 作品卡片

每张卡：标题；六步迷你进度条；当前阶段文字；时长；未发布显示预测中枢（"预测 ~4,565"，没有预测不显示），已发布显示实际播放；更新日期。点卡片进工作区。电脑上多列网格（每列最小 280），手机单列。

阶段到步骤的对应：

| 步骤 | 完成条件 |
|---|---|
| 选题 | 有对标作品或有稿子 |
| 脚本 | 阶段 ≥ 已定稿 |
| 口播 | 阶段 ≥ 已录制 |
| 成片 | 阶段 ≥ 已出成片 |
| 发布 | 已关联发布作品 |
| 复盘 | 已有复盘 |

当前步骤 = 第一个未完成的步骤；全部完成时为"复盘"。

### 3.3 作品工作区

- 顶部：标题（可改）+ 六步步骤条；已完成浅橙底 + 勾，当前橙底白字，未到灰底；点任一步切换下方内容。默认停在当前步骤。
- 各步内容：选题 = 对标拆解（没有对标时提示"这条没有对标作品"）；脚本 = 稿子 + 预测面板；口播 = 现有录制 / 转写；成片 = 现有成片；发布 = 发布文案与关联作品；复盘 = 复盘、预测对账与写法经验（从原发布页拆出）。
- 内容区居中，最大宽度 820。
- 编导对话：右下角「和编导聊」悬浮按钮（有未读时带小红点）；电脑点开为右侧抽屉（宽 400，内容区让出位置不被遮挡），手机为底部滑出面板（高 85%）。以下情况自动展开：对话里新到通知（任务完成、存笔记卡片、预测完成）、点了「让编导按这个改」、发出消息后的回复期间。关闭不清空对话。
- 提词器全屏时保持黑底白字。

- 对比度：所有文字 / 底色组合按 WCAG AA 校验（正文 ≥ 4.5:1，大字 ≥ 3:1）。上表已按此校准（写 spec 时算过：最初的 `#D9772B` 白字只有 3.2:1，改为 `#AD5614`；辅助文字、成功、警告、信息色同样加深）。单测从 tokens.css 读值计算；上线后再用浏览器读实际计算样式抽查。
- 写死颜色的文件（成片、口播面板）改为变量；提词器保留深色。

### 4.2 字体与字号

- 正文：`-apple-system, "PingFang SC", "Source Han Sans SC", "Noto Sans SC", sans-serif`。
- 大数字（总览指标、预测中枢）：`--font-display: "Songti SC", "Source Han Serif SC", Georgia, serif`，`font-variant-numeric: tabular-nums`。
- 表格、时长：等宽数字（`tabular-nums`）。
- 字号：说明 12 / 正文 14 / 卡片标题 15 粗 / 页面标题 22 粗 / 总览大数字 28。

### 4.3 形状与组件

- 卡片：圆角 16；无边框；投影 `0 1px 2px rgba(60,40,20,.06), 0 6px 18px rgba(60,40,20,.06)`；内边距 16（手机 12）；卡片间距 16（手机 12）。
- 主按钮：`--accent` 实心白字，圆角 10，高 36；次级按钮：白底 `--border-strong` 细边；文字按钮：强调色。
- 输入框：`--bg-inset` 底，圆角 10，聚焦时强调色描边。
- 胶囊（状态 / 标签）：全圆角，浅底深字。
- 图表：自己用 SVG 画（折线 + 渐变填充、横条），主系列 `--chart`、其他系列灰；不引入图表库。
- 间距沿用现有 `--s1…--s9`；圆角变量更新为 `--r-md 10`、`--r-lg 16`、`--r-xl 20`。

## 5. 总览（`/`）

自上而下：

1. **「今天」**（一块大卡，内含小卡；手机上横向滑动）
   - 要处理：回采 / 巡检失败（原因 + 去设置）、等确认的作品关联、待采纳的写法经验、等确认的存笔记卡片、预测落后提醒、待采纳的公式建议；每条一句话 + 去处理链接。
   - 在做的作品：每条一张小卡（步骤条、下一步、预测），按预测中枢降序，第一张标「先发这条」（只在有 ≥ 2 条有预测时显示）。
   - 今日对标爆款：最多 3 条（作者、倍数、选题），点开去选题页；0 条时显示"0 条 · 关注 N 个账号" + 去加对标。
   - 全部为空时：一句"今天没有要处理的，去写一条？" + 新建项目按钮。
2. **指标卡 ×4**：粉丝（较昨天 ±）、获赞、公开作品数 · 播放合计、预测准度（"对过 N 次账 · 平均偏差 X 倍"，0 次显示"—"）。
3. **账号走势**：粉丝 / 获赞 / 播放合计三条线，7 天 / 30 天切换；数据来自新的账号每日快照（§6）；记录不满 7 天时显示"已记录 N 天，满 7 天显示曲线"。
4. **作品表现对比**：每条公开作品一行——标题、播放、5 秒完播、平均观看、点赞率，数值旁横条；表头点击排序；与平时比好标绿、差标红（复盘同一把尺子：最近 10 条中位数、阈值 20%）；点行进作品（关联了项目的进工作区，没关联的打开抖音链接）。

手机：同顺序单列，指标卡两列。

## 6. 数据

```prisma
/// 账号每日快照(每晚回采写一条, 同一天覆盖)
model AccountDailySnapshot {
  day        String   @id   // YYYY-MM-DD(本机时区)
  fans       Int?
  likes      Int?
  works      Int?           // 公开作品数
  views      Int?           // 公开作品播放合计
  createdAt  DateTime @default(now())
  updatedAt  DateTime @updatedAt
}
```

- 每晚回采成功后写入；同一天重复运行覆盖当天这条。写入失败不影响回采其它步骤。
- 不做历史回填（之前没有记录）。

## 7. 出错与空状态

| 场景 | 行为 |
|---|---|
| 账号快照不满 7 天 | 走势区显示"已记录 N 天，满 7 天显示曲线" |
| 没有公开作品 | 作品对比区显示"发布第一条后这里会出现对比" |
| 没有项目 | 作品页与「今天」都引导新建 |
| 回采从未成功 | 指标卡显示"—"并在「今天」提示去设置 |
| 旧链接 | `/retro`、`/persona` 永久跳转 |

## 8. 测试与验收

- 单元：总览数据拼装（各待办来源、空状态、先发这条的条件）；步骤判定（§3.2 表）；每日快照写入与同日覆盖；旧地址跳转；作品筛选与排序；对话抽屉自动展开的三种触发；底部标签栏在窄屏出现。
- 对比度：在浏览器里读主要组合的计算样式算对比度，全部达标。
- 真机：电脑与 375 宽各走一遍五个入口与工作区六步，无横向溢出；新建 → 磨稿 → 定稿 → 预测走通；提词器仍为深色。

## 9. 不做

深色模式；拖拽排版；新的业务功能（唯一新增数据是账号每日快照）；引入新的界面或图表库；改动提词器外观。
