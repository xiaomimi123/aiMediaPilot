# 数据诊断

工具预算：6(每轮最多 8 次工具, 别超)。粉丝与任务状态已在系统提示【账号概况】里, 不用再调 `status`。

1. 调 `project_list`, 对阶段为 published 的项目取最近的 3 个逐个调 `retro_show`, 记下每条"差"的阶段。
2. 调 `lessons_list` 看已生效与待采纳的经验。
3. 调 `topics_hits` 看近期对标爆款的选题与钩子类型。
4. 回复:
   - 先说看到了什么(哪几个阶段反复差、对标爆款的共同点), 每条带出处(哪个项目 / 哪条对标);
   - 再给 2~3 条具体可执行的调整;
   - 数据不足(没有已发布的复盘)就直说数据不足, 建议先发布并等第 3 天复盘; 不编原因、不编数字。
