# 自媒体智能管理平台 — 完整开发文档

> **项目代号**: MediaPilot  
> **版本**: v1.0 MVP  
> **目标用户**: 个人自媒体博主  
> **产品形态**: 单用户本地部署（预留 SaaS 升级路径）  
> **部署方式**: Docker 容器化

---

## 一、产品概述

### 1.1 核心定位

为个人自媒体博主提供一站式内容创作、数据分析、账号运营的智能管理平台。通过 AI 能力降低内容创作门槛，通过数据可视化提升运营效率。

### 1.2 MVP 功能全景

| 模块 | 核心功能 | 优先级 |
|------|----------|--------|
| AI 内容创作 | 文案/标题/标签生成、视频脚本、封面图生成 | P0 |
| 数据分析面板 | 粉丝趋势、单篇分析、最佳发布时间 | P0 |
| 账号管理 | 小红书/抖音多账号绑定、统一视图 | P0 |
| 竞品分析 | AI 分析竞品账号内容策略 | P1 |
| 发布策略 | AI 生成发布时间/频率/内容规划建议 | P1 |
| 矩阵发布 | 多平台一键分发（预留，后续开发） | P2 |

### 1.3 平台适配

**MVP 支持:**

- **小红书** — 图文笔记为主，支持视频脚本
- **抖音** — 短视频脚本 + 封面图为主

**预留扩展（接口抽象）:**

- 微信公众号
- B 站
- 快手
- 微博

## 二、技术架构

### 2.1 推荐技术栈

```
┌─────────────────────────────────────────────────┐
│                   前端 (Frontend)                 │
│  Next.js 14 (App Router) + TypeScript            │

│  Recharts (数据可视化)                             │
│  Zustand (状态管理)                               │
└────────────────────┬────────────────────────────┘
                     │ REST API + WebSocket
┌────────────────────┴────────────────────────────┐
│                  后端 (Backend)                    │
│  Node.js + Express/Fastify + TypeScript          │
│  Prisma ORM                                      │
│  Bull (任务队列)                                   │
│  Socket.io (实时通知)                              │
└───┬──────────┬───────────┬──────────────────────┘
    │          │           │
┌───┴──┐  ┌───┴───┐  ┌───┴────────────────────┐
│ PgSQL│  │ Redis │  │ CloakBrowser + Playwright│
│数据库 │  │ 缓存  │  │    浏览器采集引擎         │
└──────┘  └───────┘  └────────────────────────┘
```

### 2.2 技术选型理由

| 技术 | 选型理由 |
|------|----------|
| **Next.js 14** | SSR/SSG 提升首屏速度，App Router 支持 Server Components，React 生态最成熟的全栈框架 |
| **TypeScript** | 全栈类型安全，大型项目必备 |
| **PostgreSQL** | 结构化数据存储（账号、笔记、指标），JSON 字段支持灵活扩展，对后续 SaaS 多租户友好 |
| **Redis** | 采集任务队列、API Key 限流、缓存热点数据 |
| **Prisma** | 类型安全 ORM，自动生成迁移，与 TypeScript 无缝配合 |
| **CloakBrowser** | 反检测浏览器，源码级 Chromium 补丁，通过 Cloudflare Turnstile，支持 Playwright API |
| **Bull** | 基于 Redis 的可靠任务队列，支持定时任务、重试、并发控制 |
| **shadcn/ui** | 可定制化的 React UI 组件库，不依赖运行时，符合现代审美 |

## 五、浏览器采集引擎设计

### 5.1 技术方案: CloakBrowser + Playwright

采用 CloakBrowser 作为反检测浏览器基座，配合 Playwright API 进行自动化采集。CloakBrowser-Manager 管理浏览器 Profile（每个平台账号对应一个独立 Profile）。

### 5.2 架构设计

```
┌──────────────────────────────────────────────┐
│              采集调度层 (Bull Queue)            │
│  定时任务 → 采集任务入队 → Worker 消费执行       │
└──────────────────┬───────────────────────────┘
                   │
```

```typescript
import { chromium } from 'playwright';

class BrowserManager {
  private managerUrl: string; // CloakBrowser-Manager API 地址

  constructor(managerUrl = 'http://localhost:8080') {
    this.managerUrl = managerUrl;
  }

  // 创建或获取浏览器 Profile
  async getOrCreateProfile(name: string, proxy?: string) {
    const res = await fetch(`${this.managerUrl}/api/profiles`, {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ name, proxy })
    });
    return res.json();
  }

  // 启动 Profile 并获取 CDP 连接地址
  async launchProfile(profileId: string) {
    const res = await fetch(
      `${this.managerUrl}/api/profiles/${profileId}/launch`,
      { method: 'POST' }
    );
    const { cdpUrl } = await res.json();
    return cdpUrl;
  }

  // 通过 CDP 连接 Playwright
  async connectPlaywright(cdpUrl: string) {
    const browser = await chromium.connectOverCDP(cdpUrl);
    const context = browser.contexts()[0];
    const page = context.pages()[0] || await context.newPage();
    return { browser, context, page };
  }

  // 停止 Profile
  async stopProfile(profileId: string) {
    await fetch(
      `${this.managerUrl}/api/profiles/${profileId}/stop`,
      { method: 'POST' }
    );
  }
}
```

```typescript
      // 注意: 小红书页面结构可能变化，需要定期维护选择器
      return {
        nickname: document.querySelector('.user-name')?.textContent?.trim(),
        // ... 其他字段
      };
    });

    return data as ProfileData;
  }

  async fetchNoteList(profileUrl: string, options?: {
    maxCount?: number;
  }): Promise<NoteListItem[]> {
    await this.page!.goto(profileUrl, { waitUntil: 'networkidle' });

    const notes: NoteListItem[] = [];
    const maxCount = options?.maxCount || 50;

    // 滚动加载更多笔记

      const newNotes = await this.page!.evaluate(() => {
        // 解析笔记卡片列表

          // ... 解析逻辑
        }));

      await this.page!.evaluate(() => window.scrollTo(0, document.body.scrollHeight));
      await this.page!.waitForTimeout(2000);

      const hasMore = await this.page!.evaluate(() => {
        return !document.querySelector('.no-more');
      });
```

```typescript
import Queue from 'bull';

const syncQueue = new Queue('sync-tasks', {
  redis: { host: 'localhost', port: 6379 }

// 定时任务: 每6小时同步一次账号数据
syncQueue.add('sync-all-accounts', {}, {
  repeat: { cron: '0 */6 * * *' },
  removeOnComplete: 100,
  removeOnFail: 50,
});

// Worker 处理任务
syncQueue.process('sync-account', async (job) => {
  const { accountId, syncType } = job.data;

  const account = await prisma.platformAccount.findUnique({
    where: { id: accountId }
  });

  const crawlerClass = getCrawlerByPlatform(account.platform);
  const crawler = new crawlerClass();

  try {
    await crawler.connect(account.browserProfileId);

    switch (syncType) {
      case 'PROFILE':
        const profile = await crawler.fetchProfile(account.profileUrl);
        await updateAccountProfile(accountId, profile);
        break;

      case 'NOTES':
        const notes = await crawler.fetchNoteList(account.profileUrl);
        await upsertNotes(accountId, notes);
        break;

      case 'METRICS':
        await snapshotAccountMetrics(accountId);
        break;
    }

    await prisma.syncTask.update({
      where: { id: job.data.taskId },
      data: { status: 'SUCCESS', finishedAt: new Date() }
    });
  } catch (error) {
    await prisma.syncTask.update({
      where: { id: job.data.taskId },
      data: { status: 'FAILED', error: error.message }
    });
  } finally {
    await crawler.disconnect();
  }
});
```

```typescript
// src/ai/image-adapters/replicate.ts (Flux / SD 等)

class ReplicateImageAdapter implements IImageAdapter {
  provider = ImageProvider.REPLICATE;
  private apiKey: string;
  private model: string;

  constructor(apiKey: string, model = 'black-forest-labs/flux-2-pro') {
    this.apiKey = apiKey;
    this.model = model;
  }

  async textToImage(params: TextToImageParams): Promise<ImageResult> {
    // 1. 创建预测任务
    const prediction = await fetch('https://api.replicate.com/v1/predictions', {
      method: 'POST',
      headers: {
        'Authorization': `Bearer ${this.apiKey}`,
        'Content-Type': 'application/json',
      },
      body: JSON.stringify({
        model: this.model,
        input: {
          prompt: params.prompt,
          negative_prompt: params.negativePrompt,
          width: params.width || 1024,
          height: params.height || 1024,
          num_outputs: params.count || 4,
          seed: params.seed,
        },
      }),
    });

    const predData = await prediction.json();

    // 2. 轮询等待结果
    let result = predData;
    while (result.status !== 'succeeded' && result.status !== 'failed') {
      await new Promise(resolve => setTimeout(resolve, 2000));
      const poll = await fetch(
        `https://api.replicate.com/v1/predictions/${result.id}`,
        { headers: { 'Authorization': `Bearer ${this.apiKey}` } }
      );
      result = await poll.json();
    }

    if (result.status === 'failed') {
      throw new Error(`生图失败: ${result.error}`);
    }

    return {
      images: result.output.map((url: string) => ({
        url,
        width: params.width || 1024,
        height: params.height || 1024,
      })),
      taskId: result.id,
    };
  }
}

    const response = await fetch(
      'https://dashscope.aliyuncs.com/api/v1/services/aigc/text2image/image-synthesis',
      {
        method: 'POST',
        headers: {
          'Authorization': `Bearer ${this.apiKey}`,

          'X-DashScope-Async': 'enable',
        },
        body: JSON.stringify({
          model: this.model,
          input: {
            prompt: params.prompt,
            negative_prompt: params.negativePrompt,
          },
          parameters: {
            size: `${params.width || 1024}*${params.height || 1024}`,
            n: params.count || 4,
            seed: params.seed,
          },
        }),
      }
    );

    const taskData = await response.json();
    const taskId = taskData.output.task_id;

    // 2. 轮询任务状态
    let taskResult;
    while (true) {
      await new Promise(resolve => setTimeout(resolve, 3000));
      const statusRes = await fetch(
        `https://dashscope.aliyuncs.com/api/v1/tasks/${taskId}`,
        { headers: { 'Authorization': `Bearer ${this.apiKey}` } }

      taskResult = await statusRes.json();

      if (taskResult.output.task_status === 'SUCCEEDED') break;
      if (taskResult.output.task_status === 'FAILED') {
        throw new Error(`通义万相生图失败: ${taskResult.output.message}`);
      }
    }

    return {
      images: taskResult.output.results.map((r: any) => ({
        url: r.url,
        width: params.width || 1024,
        height: params.height || 1024,
      })),
      taskId,
    };
  }
```

#### 6.3.7 生图工作流

```
用户创作内容
    │
    ├── 方式 A: 手动输入 Prompt 生图
    │     └── 输入 prompt → 选择服务商/模型 → 选择平台&尺寸
    │         → 生成 4 张预览 → 选择满意的 → 保存到内容
    │
    ├── 方式 B: AI 根据文案自动生成
    │     └── 选中已有文案 → 点击"AI 生成封面"
    │         → 文本 AI 先生成生图 prompt → 生图 AI 生成图片
    │         → 预览 → 选择 → 保存
    │
    └── 方式 C: 图片编辑/重绘
          └── 上传已有图片 → 描述修改需求 → AI 局部重绘
```

### 12.3 小红书发布器

```typescript
// src/publisher/xiaohongshu.ts

import { Page } from 'playwright';
import { BrowserManager } from '../crawler/browser-manager';

class XHSPublisher implements IPublisher {
  platform = Platform.XIAOHONGSHU;
  private browserManager: BrowserManager;

  async checkLoginStatus(profileId: string): Promise<boolean> {
    const cdpUrl = await this.browserManager.launchProfile(profileId);
    const { page } = await this.browserManager.connectPlaywright(cdpUrl);

    try {
      await page.goto('https://creator.xiaohongshu.com/publish/publish', {
        waitUntil: 'networkidle'
      });
      // 如果跳转到登录页说明未登录
      const url = page.url();
      return !url.includes('login');
    } finally {
      await this.browserManager.stopProfile(profileId);
    }
  }

  async publishImageText(params: ImageTextPublishParams): Promise<PublishResult> {
    const cdpUrl = await this.browserManager.launchProfile(params.profileId);
    const { page } = await this.browserManager.connectPlaywright(cdpUrl);

    try {
      // 1. 打开小红书创作者中心 - 发布页面
      await page.goto('https://creator.xiaohongshu.com/publish/publish', {
        waitUntil: 'networkidle'
      });
      await this.randomDelay(2000, 4000);

      // 2. 选择"上传图文"标签（小红书默认是视频）
      const imageTextTab = await page.locator('text=上传图文');
      if (await imageTextTab.isVisible()) {
        await imageTextTab.click();
        await this.randomDelay(1000, 2000);
      }

      // 3. 上传图片
      const fileInput = await page.locator('input[type="file"]');
      await fileInput.setInputFiles(params.images);
      // 等待所有图片上传完成
      await page.waitForSelector('.upload-complete', {
        timeout: 60000  // 图片上传最多等 60 秒
      });
      await this.randomDelay(2000, 3000);

      // 4. 填写标题
      const titleInput = await page.locator('#title-input, [placeholder*="标题"]');
      await titleInput.click();
      await this.humanType(page, titleInput, params.title);
      await this.randomDelay(500, 1000);

      // 5. 填写正文
      const contentInput = await page.locator('#content-input, [placeholder*="正文"]');
      await contentInput.click();
      await this.humanType(page, contentInput, params.content);
      await this.randomDelay(1000, 2000);

      // 6. 添加标签
      for (const tag of params.tags) {
        // 输入 # 触发标签选择
        await contentInput.type(' #' + tag);
        await this.randomDelay(500, 1000);
        // 尝试选择下拉中的第一个匹配标签
        const tagOption = await page.locator('.tag-suggestion-item').first();
        if (await tagOption.isVisible({ timeout: 2000 })) {
          await tagOption.click();
        }
        await this.randomDelay(300, 600);
      }

      // 7. 截图预览（保存为发布记录）
      const previewScreenshot = await page.screenshot({ fullPage: false });
```

```typescript
// src/jobs/publish-scheduler.ts

import Queue from 'bull';
import { prisma } from '../lib/prisma';
import { XHSPublisher } from '../publisher/xiaohongshu';
import { DouyinPublisher } from '../publisher/douyin';

const publishQueue = new Queue('publish-tasks', {
  redis: { host: 'localhost', port: 6379 }
});

// ---- 定时发布扫描器 ----
// 每分钟检查一次是否有到时间的发布任务
publishQueue.add('scan-scheduled', {}, {
  repeat: { cron: '* * * * *' },
  removeOnComplete: true,
});

publishQueue.process('scan-scheduled', async () => {
  const now = new Date();
  const readyTasks = await prisma.publishTask.findMany({
    where: {
      status: 'APPROVED',
      mode: 'SCHEDULED',
      scheduledAt: { lte: now },
    },
    include: { targets: true }
  });

  for (const task of readyTasks) {
    await publishQueue.add('execute-publish', {
      publishTaskId: task.id
    }, {
      attempts: 1,  // 任务级不重试，target 级单独重试
      removeOnComplete: true,
    });
  }
});

// ---- 发布执行器 ----
publishQueue.process('execute-publish', async (job) => {
  const { publishTaskId } = job.data;

  // 更新任务状态为 PUBLISHING
  await prisma.publishTask.update({
    where: { id: publishTaskId },
    data: { status: 'PUBLISHING' }
  });

  const task = await prisma.publishTask.findUnique({
    where: { id: publishTaskId },
    include: {
      targets: { include: { account: true } },
      content: true
    }
  });

  if (!task) return;

  const results: { targetId: string; success: boolean }[] = [];

  // 按平台顺序执行，每个平台间间隔 30-60 秒
  for (const target of task.targets) {
    if (target.status === 'CANCELLED') continue;

    try {
      // 更新 target 状态
      await prisma.publishTarget.update({
        where: { id: target.id },
        data: { status: 'PUBLISHING', startedAt: new Date() }
      });

      // 通过 WebSocket 通知前端进度
      notifyProgress(publishTaskId, target.id, 'PUBLISHING');

      // 获取对应平台的发布器
      const publisher = getPublisher(target.platform);

      // 先检查登录态
      const isLoggedIn = await publisher.checkLoginStatus(
        target.account.browserProfileId
      );
      if (!isLoggedIn) {
        throw new Error(`${target.platform} 账号登录态已失效，请重新登录`);
      }

      let result: PublishResult;

      // 根据内容类型选择发布方法
      const mediaFiles = target.mediaFiles as any[];
      const hasVideo = mediaFiles?.some(f => f.type === 'video');

      if (hasVideo) {
        result = await publisher.publishVideo({
          profileId: target.account.browserProfileId,
          title: target.adaptedTitle || task.title,
          description: target.adaptedContent || task.content.body,
          videoPath: mediaFiles.find(f => f.type === 'video').path,
          coverImage: target.coverImage || undefined,
          tags: target.adaptedTags,
        });
      } else {
        result = await publisher.publishImageText({
          profileId: target.account.browserProfileId,
          title: target.adaptedTitle || task.title,
          content: target.adaptedContent || task.content.body,
          images: mediaFiles?.filter(f => f.type === 'image').map(f => f.path) || [],
          tags: target.adaptedTags,
        });
      }

      // 更新 target 结果
      await prisma.publishTarget.update({
        where: { id: target.id },
        data: {
          status: result.success ? 'SUCCESS' : 'FAILED',
          publishedUrl: result.publishedUrl,
          platformNoteId: result.platformNoteId,
          error: result.error,
          finishedAt: new Date(),
        }
      });

      results.push({ targetId: target.id, success: result.success });
      notifyProgress(publishTaskId, target.id, result.success ? 'SUCCESS' : 'FAILED');
    } catch (error: any) {
      await prisma.publishTarget.update({
        where: { id: target.id },
        data: {
          status: 'FAILED',
          error: error.message,
          finishedAt: new Date(),
        }
      });

      results.push({ targetId: target.id, success: false });
      notifyProgress(publishTaskId, target.id, 'FAILED');
    }

    // 平台间随机间隔 30-60 秒，避免同时操作
    await randomDelay(30000, 60000);
  }

  // 计算最终任务状态
  const allSuccess = results.every(r => r.success);
  const allFailed = results.every(r => !r.success);
  const finalStatus = allSuccess
    ? 'COMPLETED'
    : allFailed
      ? 'FAILED'
      : 'PARTIAL_FAILED';

  await prisma.publishTask.update({
    where: { id: publishTaskId },
    data: { status: finalStatus }
  });

  notifyTaskComplete(publishTaskId, finalStatus);
});

// ---- 单平台重试 ----
publishQueue.process('retry-target', async (job) => {
  const { publishTaskId, targetId } = job.data;

  const target = await prisma.publishTarget.findUnique({
    where: { id: targetId },
    include: { account: true, publishTask: { include: { content: true } } }

    data: {
      status: 'PUBLISHING',
      retryCount: { increment: 1 },
      error: null,
      startedAt: new Date(),
    }
  });

  // 重新执行发布逻辑（同上，略）

});
```

```typescript
class AccountBindingService {

   * 绑定平台账号

  async bindAccount(params: {

    );

    // 2. 启动 Profile
    await this.browserManager.launchProfile(profile.id);

    // 3. 打开平台登录页
    const loginUrls: Record<Platform, string> = {
      XIAOHONGSHU: 'https://creator.xiaohongshu.com/login',

    };
```

## 十三、注意事项与风险

### 13.1 法律合规

- 采集行为需遵守各平台用户协议和 robots.txt
- 仅采集公开可见的数据，不采集私密内容
- API Key 加密存储，使用 AES-256-GCM 对称加密
- 用户数据本地存储，不上传第三方

### 13.2 反爬风险

- 小红书/抖音反爬策略更新频繁，采集器需定期维护
- 建议限制采集频率，避免高频请求触发封禁
- CloakBrowser 的 C++ 级别指纹修改提供了强反检测能力
- 预留手动录入数据作为降级方案

### 13.3 性能考量

- 采集任务异步执行，不阻塞主应用
- 大量历史数据使用分页查询
- 热点数据（Dashboard 概览）使用 Redis 缓存，TTL 5 分钟
- 图表数据按需加载，首屏优先加载核心指标
